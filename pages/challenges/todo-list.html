لیست کارها (To-Do List)

جاوا اسکریپت سطح: متوسط

برنامه‌ای بساز که کاربر بتواند کار جدید اضافه کند، آن را به‌عنوان «انجام‌شده» علامت بزند و در صورت نیاز حذف کند.

JavaScript DOM Array

هدف از این چالش

  • ساخت پویا‌ی عنصر (createElement)
  • مدیریت رویدادها روی عناصر پویا
  • کار با آرایه برای نگه‌داری داده‌ها

شرایط و ملزومات

  • فیلد ورودی و دکمه‌ی افزودن کار جدید
  • نمایش لیست کارها در صفحه
  • امکان تیک زدن (انجام‌شده) با خط خوردن روی متن
  • دکمه‌ی حذف برای هر کار

نمونه ورودی و خروجی

ورودی نمونه

خرید نان، تماس با دوست

خروجی نمونه

لیستی با دو آیتم که هرکدام قابل تیک زدن و حذف هستند.

قالب شروع

می‌تونی با این قالب شروع کنی و ادامه‌اش بدی:

const input = document.querySelector('#new-task');
const list = document.querySelector('#task-list');

// ادامه‌ی کد خودت رو اینجا بنویس
