صفحه محصول فروشگاهی

طراحی وب سطح: سخت

یک صفحه‌ی معرفی محصول برای فروشگاه اینترنتی طراحی کن؛ شامل گالری تصاویر، قیمت، توضیحات، انتخاب تعداد و دکمه‌ی افزودن به سبد خرید.

HTML CSS E-commerce

هدف از این چالش

  • چیدمان دوستونی واکنش‌گرا
  • طراحی گالری تصویر ساده
  • طراحی دکمه‌های افزایش/کاهش تعداد

شرایط و ملزومات

  • گالری با یک تصویر اصلی و چند تصویر کوچک
  • نام محصول، قیمت و امتیاز (ستاره)
  • توضیحات کامل محصول
  • کنترل تعداد (+ / -) و دکمه‌ی افزودن به سبد خرید
