رابط کاربری ماشین‌حساب

طراحی وب سطح: متوسط

فقط ظاهر یک ماشین‌حساب را با HTML و CSS بساز: صفحه‌ی نمایش و دکمه‌های عددی و عملگرها در قالب گرید. (نیازی به محاسبه‌ی واقعی نیست، تمرکز روی طراحی است)

HTML CSS Grid

هدف از این چالش

  • چیدمان گرید (CSS Grid)
  • طراحی دکمه با سایه و افکت فشرده‌شدن
  • رنگ‌بندی متفاوت برای دکمه‌های عدد و عملگر

شرایط و ملزومات

  • صفحه نمایش بالای ماشین‌حساب
  • دکمه‌های ۰ تا ۹
  • دکمه‌های عملگر (+ - × ÷ =)
  • دکمه پاک کردن (C)
