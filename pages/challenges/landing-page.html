صفحه فرود شخصی (Landing Page)

طراحی وب سطح: ساده

با HTML و CSS یک صفحه فرود ساده برای معرفی خودت بساز؛ شامل عنوان، توضیح کوتاه، عکس یا آواتار و چند لینک شبکه‌ی اجتماعی.

HTML CSS Layout

هدف از این چالش

  • ساختار پایه‌ی HTML
  • چیدمان با CSS (Flexbox یا Grid)
  • استایل‌دهی به دکمه و لینک‌ها

شرایط و ملزومات

  • یک هدر با نام و عنوان شغلی
  • بخش «درباره من» با چند خط توضیح
  • حداقل ۳ لینک به شبکه‌های اجتماعی به شکل دکمه
  • طراحی واکنش‌گرا (Responsive) برای موبایل
