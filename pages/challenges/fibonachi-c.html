دنباله فیبوناچی در C

زبان سی سطح: متوسط

برنامه‌ای بنویس که تعداد جمله‌های دنباله فیبوناچی را از کاربر بگیرد و آن‌ها را با استفاده از حلقه چاپ کند.

C دنباله حلقه

هدف از این چالش

  • حلقه و متغیرهای کمکی
  • منطق دنباله‌ی تکراری (iterative)

شرایط و ملزومات

  • دریافت تعداد جمله از کاربر
  • تولید دنباله با شروع از 0 و 1
  • چاپ دنباله در یک خط

قالب شروع

می‌تونی با این قالب شروع کنی و ادامه‌اش بدی:

#include 

int main() {
    int n, a = 0, b = 1, next;
    scanf("%d", &n);

    // ادامه‌ی کد خودت رو اینجا بنویس

    return 0;
}

راهنمایی 1

راهنمایی 2

با یک متغیر موقت مقادیر a و b را در هر مرحله جابه‌جا کن
